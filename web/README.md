# Front-end

Interface do Gerenciador de Projetos, em React, TypeScript e Vite.

- Como rodar o projeto: [README principal](../README.md)
- Páginas, componentes e estrutura de pastas: [docs/frontend.md](../docs/frontend.md)

## Comandos

| Comando | O que faz |
|---|---|
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm test` | Testes (Vitest) |
| `npm run lint` | Lint (oxlint) |
| `npm run format` | Formatação (Prettier) |
